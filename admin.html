Como funciona

Este site é 100% estático (sem servidor), então as alterações que você fizer aqui aparecem só no seu navegador, como pré-visualização. Para que todo mundo veja as mudanças no site publicado, clique em "Gerar código para publicar", copie o resultado e cole no arquivo js/config.js antes de subir para o GitHub/Hostinger — o mesmo processo que você já usa no site do MasQbom.

Publicar as alterações no site de verdade

  1. Clique em "Gerar código" abaixo.
  2. Copie todo o texto gerado.
  3. Abra o arquivo js/config.js no seu computador (ou no GitHub).
  4. Substitua os trechos carrossel: [...] e galeria: [...] pelo código copiado.
  5. Salve e suba os arquivos para a Hostinger/GitHub, como de costume.

Dica: itens adicionados por upload de arquivo viram um código bem longo (imagem embutida). Isso funciona, mas deixa o site mais pesado — prefira colar um link de imagem/vídeo já hospedado sempre que possível.
